Pause everything,
with one click.

Freeze instantly pauses every playing video and audio — especially YouTube — across all your open tabs. Click again and only what Freeze paused resumes. Whatever you'd already paused stays paused.

Install in Brave

  1. 1

    Download the repo, then run npm run icons once to generate the icons.

  2. 2

    Open brave://extensions in Brave.

  3. 3

    Turn on Developer mode (top-right toggle).

  4. 4

    Click Load unpacked and pick the folder containing manifest.json.

  5. 5

    Pin Freeze to the toolbar — and start freezing.

Works the same in Chrome (chrome://extensions) and Edge (edge://extensions).
